# Potential follow-ups

- Configurable Cleanup strength, including an opt-out and a more stylistic mode, after the MVP's Conservative Cleanup behavior meets its trust and latency targets.
- Spoken phrase expansion for saved values after the core Dictation pipeline is trustworthy.
- Deliberate multilingual recognition, Cleanup, vocabulary, and evaluation support after the English release gates are met.
- Automatic Personal Vocabulary learning only if it can be transparent, local, reversible, and easy to audit.
- A toggle-style Recording interaction as an accessibility preference without changing press-and-hold as the default.
- A complete offline installer containing the application and current Model Pack.
- Configurable history retention, including indefinite retention, as an explicit preference rather than the default.
- Windows and Linux products after the native macOS architecture and interaction have proven themselves; they are not compatibility constraints on the Swift codebase.
