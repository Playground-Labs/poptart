# Rebuild Poptart in a new repository

Poptart will be redesigned as a new application in a new repository rather than incrementally replacing the Handy-derived architecture in the existing repository. This clean break gives Poptart ownership of its architecture, terminology, release process, and technical direction; working behavior may be reimplemented or selectively ported, but compatibility with the existing code structure and upstream development is not a design constraint. Any reused MIT-licensed code will retain the attribution required by its license.
