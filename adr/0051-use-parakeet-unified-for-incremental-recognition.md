# Use Parakeet Unified for incremental recognition

Poptart will use FluidAudio's Parakeet Unified English 0.6B model with the 640 millisecond streaming configuration and int8 encoder instead of Parakeet TDT v2. FluidAudio 0.15.6 does not produce timely incremental hypotheses from the TDT v2 sliding-window path for short Dictations, while Unified provides real partial transcription, comparable final recognition quality, punctuation and capitalization, direct offline loading, and a public Personal Vocabulary integration. This selection is provisional until the exact production artifact passes first-partial, key-up-to-final, vocabulary, quality, memory, and p99 Completion Deadline benchmarks on the physical 8 GB M1 baseline. If it fails, Poptart will benchmark FluidAudio Nemotron Streaming 560 next rather than build a custom pseudo-streaming TDT pipeline.
