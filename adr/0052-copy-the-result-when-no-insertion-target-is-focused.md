# Copy the result when no Insertion Target is focused

When the person presses the Dictation shortcut with no editable Insertion Target focused, Poptart will record normally instead of refusing with a failure Indicator. It recognizes speech, runs Cleanup without cursor-local Target Context, places the completed text on the system clipboard, retains the outcome in encrypted history, and shows a copied-to-clipboard Indicator state distinct from the target-change result. This Clipboard Dictation deliberately replaces the previous clipboard contents, as the target-change behavior in ADR 0046 already does. A focused secure control is never a Clipboard Dictation and remains blocked exactly as ADR 0047 specifies; Poptart neither records nor copies private speech for a secure control. A missing Accessibility permission also remains a failure rather than a Clipboard Dictation.
